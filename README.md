# AGY — Creative Digital Agency Studio

A high-performance, single-page immersive 3D landing page for **AGY**, a creative digital agency specializing in WebGL experiences, interactive 3D web applications, and kinetic brand systems.

## 🌟 Key Features & Design System

- **Design & Vibe**: Dark, minimal, and premium aesthetic. Matte dark charcoal background (`#121212`), crisp white typography, and vibrant electric blue (`#00F0FF`) & neon violet (`#A855F7`) lighting accents.
- **Hero Section**:
  - Full-screen layout with an interactive floating 3D geometric abstract masterpiece rendered in real-time with Three.js.
  - Smooth cursor tracking (`lerp`) and scroll dynamics.
  - Centered headline: **"We Build Digital Realities"** with subtle subheadline and glowing call-to-action buttons.
  - Real-time 60FPS WebGL performance metrics strip.
- **Interactive Services Grid**:
  - 6 key expertise cards featuring 3D tilt calculations (`rotateX` & `rotateY` based on mouse coordinates).
  - Hover-reactive 3D card borders with radial cursor light-glow beam effects.
- **Selected Project Timeline**:
  - Horizontal-scroll timeline track showcasing featured agency builds (NEBULA-X, QUANTUM PROTOCOL, SYNTHESIS AI, VORTEX HYPERCAR).
  - Case study preview cards with impact metrics, tech tags, and interactive detail modals.
- **Interactive Project Cost / Estimator Calculator**:
  - Real-time calculation engine with animated number counter.
  - Select project scope, 3D complexity level, optional feature modules, and timeline urgency.
  - Instant investment breakdown list and "Book Discovery Call" modal trigger.
- **Minimalist Contact Footer**:
  - Active agency status badge (`● ACCEPTING NEW PROJECTS FOR Q3/Q4`).
  - Direct inquiry form, WhatsApp quick chat link, social links, and smooth back-to-top button.

## 🛠️ Built With

- **HTML5 & CSS3**: Native CSS Custom Properties, Glassmorphism, CSS 3D Transforms, Responsive Grid/Flexbox.
- **Three.js & WebGL**: Interactive background particle field + 3D abstract sculpture.
- **JavaScript (ES6+)**: IntersectionObserver for staggered animations, interactive estimator state math, dynamic modals.
- **Lucide Icons & Google Fonts**: 'Outfit', 'Inter', and 'JetBrains Mono'.
