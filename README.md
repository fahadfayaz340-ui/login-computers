# Login Computers - Website

A premium, modern, and highly interactive single-page landing website designed for **Login Computers** (located in Chadoora, Budgam).

## 🚀 Features

- **WOW Design Aesthetics**: Futuristic dark theme with glowing cyan (`#00f2fe`) and deep purple (`#9b51e0`) neon accent gradients.
- **Fully Responsive**: Works beautifully on mobile phones, tablets, laptops, and wide monitors.
- **Sticky Glassmorphic Navigation**: Adapts dynamically as users scroll through different sections of the page.
- **Interactive Price Estimator Widget**: Calculates real-time starting price estimates depending on:
  - Device type (Laptop, Desktop, Custom PC)
  - Desired repair/upgrade (SSD upgrades, RAM upgrades, Screen replacements, Motherboard repairs, etc.)
- **WhatsApp Integration**:
  - The Estimator's "Book Service" button automatically generates a custom message detailing their selected device type, desired service, and estimated price, and pre-fills it in WhatsApp directly to **9906405769**.
  - The contact form generates a custom inquiry WhatsApp text format and redirects the user with a single click.
- **Local Focus**: Highlighting the shop address (Chadoora, Budgam) and featuring an interactive visual location map card linking directly to Google Maps navigation.
- **No External Weight**: Built using Vanilla HTML5, premium responsive CSS3, and dynamic modern JavaScript. Heavy frames are avoided for blazing-fast loading speeds.

## 🛠️ How to Open and View

1. **Direct Open**:
   - Simply navigate to the [login-computers](file:///C:/Users/fahad/login-computers) directory on your computer and double-click `index.html` to open it instantly in Google Chrome, Microsoft Edge, Firefox, or Safari.

2. **Using a Local Server**:
   - Open your terminal inside `C:\Users\fahad\login-computers` and run:
     ```bash
     npx serve
     ```
     or if Python is installed:
     ```bash
     python -m http.server 8000
     ```
   - Open `http://localhost:8000` (or the port specified) in your browser.
